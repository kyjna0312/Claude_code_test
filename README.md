# ⌨️ 키보드 입력 테스트

간단하고 깔끔한 디자인의 키보드 입력 테스트 프로그램입니다.

## 기능

- 🖱️ **시각적 피드백**: 버튼 클릭시 검은색으로 변하며 애니메이션 효과 제공
- ⌨️ **실제 키보드 입력**: 마우스 클릭뿐만 아니라 실제 키보드 입력도 감지
- 📝 **입력 텍스트 표시**: 입력된 모든 키가 실시간으로 표시됨
- 📊 **통계 기능**: 총 입력 키 수와 가장 많이 누른 키 추적
- 🔄 **초기화 기능**: 통계 및 입력 내용을 언제든 초기화 가능
- 🎨 **미니멀 디자인**: 흰색 기반의 심플하고 깔끔한 UI

## 사용 방법

1. 브라우저에서 `keyboard-test.html` 파일 열기
2. 화면의 키보드 버튼을 클릭하거나 실제 키보드로 입력
3. 입력된 텍스트와 통계 확인
4. "초기화" 버튼으로 데이터 리셋

## 지원 키

- 숫자: 0-9
- 알파벳: A-Z
- 스페이스 바

## 기술 스택

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
